# Declan Kramper

I build things. Mostly software. Often AI-native. Usually because a workflow is broken, a product should exist, or something would be more fun if I made it myself.

I'm a product person who codes, which means I care less about stacks in the abstract and more about outcomes: faster workflows, sharper decisions, better UX, more leverage, and things that are actually shipped.

If you want the broader context, writing, and screenshots behind a lot of this work: [portfolio](https://declankramper.com) · [writing](https://declankramper.com/writes) · [LinkedIn](https://www.linkedin.com/in/declan-kramper)
